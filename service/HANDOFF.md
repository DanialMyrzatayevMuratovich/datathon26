- Результаты и оригиналы: `runs/jobs/<uuid>/`; JSON заменяется атомарно. После рестарта завершённые задачи доступны, незавершённые получают failed. Завершённые задачи удаляются через 24 часа. В каталоге создаётся локальный `.gitignore` с `*`.

- Скрипты запуска и туннеля: `scripts/run_service.sh`, `scripts/tunnel.sh`. Ctrl+C/TERM останавливает запущенные ими процессы; порт 8000 после проверки свободен. На Mac работает caffeinate.

## Danial / агент danial — следующие действия в вашей зоне

1. **R1, зависимость:** добавить `python-multipart` в `pyproject.toml` и `uv.lock`: `uv add 'python-multipart>=0.0.32'`. На ноутбуке Асылбека временно установлена 0.0.32 через `uv pip install`, общие файлы зависимостей не менялись. Без записи в lockfile свежий `uv sync` и Docker не воспроизводят загрузку файлов. Dockerfile специально проверяет импорт, чтобы сборка не считалась готовой при отсутствии парсера. После добавления удалить временную оговорку в README через asylbek.
2. **Конфиденциальность:** добавить `runs/jobs/` в корневой `.gitignore`. Пока защита есть внутри каталога задач и в локальном `.git/info/exclude` Асылбека. Видео/результаты не коммитить.
3. **Общий Ruff:** `data/laws/build_catalog.py`: E501 на строках 26, 44, 59, 63, 90; B905 на строке 119 (`zip(..., strict=...)`). `vision/__init__.py`: E501 на строке 7. Эти замечания пришли из main, наша зона их не изменяла. После исправления: `uv run ruff check .`.
4. **R7, интеграция:** сохранить `vision.analyze(path, progress) -> VideoAnalysis`. Callback принимает `(float от 0 до 1, stage: str)`. Результат сохраняет воркер; API не делает выводов о нарушениях. `failed` никогда не превращается в `no_violation`. Каждый job запускается отдельным Python-процессом: инициализация весов входит в бюджет 270 с; два одновременных процесса могут требовать много памяти. Подготовить веса заранее; воркер включает `HF_HUB_OFFLINE=1` и `TRANSFORMERS_OFFLINE=1`.
5. **R4/R5, основной Mac:** после готовности весов и `VISION_ENGINE=real` запустить через README. Проверить пять реальных роликов, скорость и память. При необходимости согласовать `SERVICE_WORKERS=1`, но учесть общую очередь и лимит 270 с. Контейнер Linux не подтверждает совместимость MLX — основной способ запуска на M4 нативный.
6. **Публичная сдача:** проверить `bash scripts/run_service.sh --tunnel` на стабильной сети либо заранее настроенный named tunnel. Сообщить HTTPS URL; ключ передать человеку лично. Проверить URL с телефона через мобильную сеть. Не выдавать временный URL остановленного туннеля за рабочий.

## Bigali / агент UI — подключение

- Положить статические файлы в `ui/`, без CDN. API обслуживает UI на том же origin; CORS не нужен.
- POST multipart, единственное поле `file`; затем опрос `/api/v1/jobs/{id}/details` для прогресса, ошибок и правил. Все запросы, включая video, с `X-API-Key`. Не вшивать ключ в JS/HTML, не отправлять в URL, не сохранять в Git.
- Для `<video>` получить файл через `fetch` с ключом и создать Blob URL, затем освободить его через `URL.revokeObjectURL`. При `429` показать ожидание и повторить загрузку по действию пользователя; при `failed` показать ошибку из details.
- Health сообщает `engine=mock|real`; явно обозначить mock в демо. Тестовый вердикт не является выводом реальной модели.
