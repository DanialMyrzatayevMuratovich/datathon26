# Нормативная база: источники и сопоставление с нарушениями

Итог: каталог [`data/laws/rules_catalog.json`](../data/laws/rules_catalog.json) — для каждого из 12 типов (T1–T12, см. `docs/VIOLATIONS.md`) реальные пункты актов РК с **дословной цитатой**. Сборщик [`data/laws/build_catalog.py`](../data/laws/build_catalog.py) проверяет, что каждая цитата буквально есть в тексте пункта, иначе падает. Сервис берёт правило из каталога — ничего не генерирует, поэтому выдуманных ссылок быть не может (критерий 4, 15 баллов).

## Сопоставление: тип → пункт

| Тип | Пункт(ы) | Основание | Суть нормы |
|---|---|---|---|
| T1 Ценности оставлены без присмотра | 231: п. 20 | прямое | ранее принятые наличные хранятся в устройствах на рабочем месте, закрывающихся на ключ |
| T2 Наличные открыто на столе при клиенте | 231: п. 20 | прямое | на рабочем месте — только деньги текущего клиента, остальные — в запираемых устройствах |
| T3 Ключ оставлен в замке сейфа | 231: п. 80; п. 20 | трактовка | хранение ключей от устройств на рабочем месте должно исключать несанкционированное использование |
| T4 Сейф оставлен открытым | 231: п. 20 | трактовка | наличные хранятся в устройствах, закрывающихся на ключ |
| T5 Компьютер не заблокирован при уходе | 53 (АРРФР): п. 71 подп. 9); п. 53 | трактовка | блокировка рабочей станции, меры защиты рабочих станций |
| T6 Дверь кассы не закрыта | 14: п. 16 подп. 1); п. 8 | трактовка | касса — отдельный вход с закрывающейся на замок дверью; кассовый узел изолирован |
| T7 Посторонний в кассовой зоне | 14: п. 8; 231: п. 14 | трактовка | изоляция кассового узла; исключение условий для хищения |
| T8 Пересчёт не в присутствии клиента | 231: п. 20; п. 31 подп. 4) | прямое | принимаются и пересчитываются в присутствии клиента |
| T9 Операция с наличными вручную без счётной машины | 231: п. 19 подп. 2); п. 9; п. 31 подп. 4) | трактовка | полистный пересчёт с проверкой подлинности; оборудование для проверки подлинности |
| T10 Приём инкассаторской сумки без проверки | 231: п. 24 | прямое | препроводительный документ, целостность сумки, правильность пломбирования |
| T11 Личные вещи на рабочем месте | 231: п. 12 | прямое | личные вещи работников хранятся вне кассового узла |
| T12 Приём пищи на рабочем месте | 231: п. 12 | трактовка | продукты — личные вещи вне кассового узла; отдельной нормы о приёме пищи нет |

**Как писать в ответе сервиса.** Для «прямых» — «Нарушен п. N Правил…». Для «трактовки» — «Может противоречить п. N …» плюс поле `why` из каталога. Сервис **не утверждает** уголовных составов (ТЗ, раздел 7): ст. 189 УК РК «Присвоение или растрата» в выдачу не включаем даже для Х-1 — это вывод следствия, а не видео.

## Как пересобрать
```bash
# тексты актов уже в data/laws/*.csv; при обновлении — скачать заново страницы zakon.uchet.kz/rus/docs/<код>
uv run python data/laws/build_catalog.py      # проверит цитаты и пересоберёт rules_catalog.json
```
