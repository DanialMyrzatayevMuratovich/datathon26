## Изменения и проверки Асылбека

- `service.quality` пересчитывает сохранённые predictions без моделей/видео. Проверяет покрытие всех меток и максимальное однократное сопоставление событий одного типа в пределах ±1/±2 с. Пропущенные видео не дают «100%»: полная accuracy = null, CLI exit 2. Exit 0 означает корректность отчёта, не качество модели.
- [reports/quality-baseline.json](reports/quality-baseline.json) и [reports/quality-latest.json](reports/quality-latest.json) содержат метаданные и SHA256 входов, без кадров и описаний. Полный план для агента Даниала — [QUALITY_PLAN.md](QUALITY_PLAN.md).
- `service.cli check` поддерживает пять разных входов с привязкой результата к файлу. `--expect-engine real` проверяет health до загрузки и не принимает mock вместо real; в отчёте есть type_id/таймкод для сравнения с прямым прогоном.
- 16 новых целевых тестов прошли: однократное matching, неправильный тип при верном времени, неполное покрытие, дубликаты видео/событий, неправильные таймкоды, смешанные входы, запрет mock при real-приёмке. Полный прогон: **59 passed / 2 skipped**, Ruff чистый; checkpoint — `docs/PROGRESS.md`.

## Следующее решение по хосту
