# Insights: от цифр к истории, которую жюри запомнит

Инсайт — это **утверждение + доказательство из данных + действие для банка**. «Признак X важен» — не инсайт. «Клиенты с загрузкой лимита > 80% уходят в просрочку в 3,1 раза чаще; банк может предлагать им реструктуризацию до первой просрочки» — инсайт.

1. **Сырьё** (ничего не считай вручную, если оно уже посчитано):
   - `outputs/eda/report.md` (нет → `uv run python -m app.cli eda`): сигнал каждого признака, разброс target по категориям, сдвиг train→test, время.
   - последний сильный `runs/<run_id>/report.md`: важность признаков и «Сегменты по топ-признакам» (lift по бинам).
   - `docs/TASK.md` и `docs/REQUIREMENTS.md`: что важно кейсодателю; `docs/DOMAIN-FINANCE.md` §4 — какие бизнес-метрики банк считает.
2. **Гипотезы** — 10–12 кандидатов: топ-признаки модели, сегменты с lift ≥ 1,5× или ≤ 0,67× при доле ≥ 5% строк, тренды во времени, взаимодействия двух признаков (сегмент × канал), аномалии и качество данных (тоже инсайт: «в 8% заявок доход не указан, и они рискованнее в 2 раза»).
3. **Проверка каждой** — в `notebooks/` или скриптом в своей зоне, через агрегаты:
   - размер сегмента (строк, доля), уровень target и lift с доверительным интервалом (бутстреп или биномиальный CI); маленький сегмент или CI через 1 → отбрось;
   - устойчивость: держится ли на train и по времени (две половины периода);
   - причинность не заявляем: «связано с», а не «вызывает».
4. **Отбор 5–7** по силе × размеру сегмента × понятности банку. Для каждого — график (один вывод в заголовке, подписанные оси, без лишних цветов; скилл `dataviz`, если есть) в `outputs/figures/insight_<n>.png`.
5. **Бизнес-эффект** — оценка, а не обещание: формула + допущения, например «если не выдавать кредиты 5% самым рискованным по модели: −X% дефолтов при −5% выдач; при среднем чеке Y и LGD Z это ≈ N тенге на 10 000 заявок (оценка)». Допущения — явно, источники — ссылками.
6. **`docs/INSIGHTS.md`** — по шаблону файла: заголовок-утверждение, цифры, график, действие для банка, ограничения, как воспроизвести (команда/ноутбук). Сверху — «главная история в 3 предложениях».
7. `scripts/msg.sh all "[INSIGHT] docs/INSIGHTS.md: <главный инсайт одной строкой>"` → `scripts/checkpoint.sh "insights: <n> findings with figures (R-ID)"`.
