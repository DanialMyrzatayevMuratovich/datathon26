# Нормативная база: источники и сопоставление с нарушениями

Каталог [`data/laws/rules_catalog.json`](../data/laws/rules_catalog.json) содержит T1–T13 и резервный T0 с пунктами актов РК и **дословными цитатами**. Сборщик [`data/laws/build_catalog.py`](../data/laws/build_catalog.py) проверяет цитаты по локальному тексту; сервис берёт ссылки из каталога, не генерирует их. Это защищает от выдуманных цитат, но **не доказывает актуальность редакции и применимость нормы к конкретному видео**. Наличие типа в каталоге не означает работающий детектор. [Сценарии, исключения и фактическое покрытие](SCENARIO_GUIDE.md).

**Как писать в ответе сервиса.** Для прямых норм — «Признаки возможного нарушения п. N Правил…»; для трактовки — «Может противоречить п. N …» плюс `why`. `basis=direct` означает прямое требование в тексте, а не доказанность события. Сервис **не утверждает** уголовных составов (ТЗ, раздел 7); умысел и хищение не выводятся из движения денег на видео. П.12 содержит разрешённые предметы, п.32 — исключения при выдаче упаковок, п.42 — исключение для приёма/выдачи клиенту; см. [шпаргалку](SCENARIO_GUIDE.md).

## Как пересобрать
```bash
# тексты актов уже в data/laws/*.csv; при обновлении — скачать заново страницы zakon.uchet.kz/rus/docs/<код>
uv run python data/laws/build_catalog.py      # проверит цитаты и пересоберёт rules_catalog.json
```
