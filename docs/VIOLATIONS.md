## Чистые ролики — как выглядит правильная работа
Пересчёт **на счётной машине при клиенте**; сейф после взятия денег **закрывается**, ключ **вынимается**; перед уходом **экран блокируется / ноутбук закрывается**; войдя, кассир **закрывает дверь**; инкассатор **предъявляет документ**, сумка проверяется. Эти пары «чисто vs нарушение» в одном ракурсе — лучший материал для правил и для объяснения в описании.

## Что это значит для решения
1. **Большинство типов — «состояние при уходе» (T1, T3, T4, T5) и «люди/дверь» (T6, T7, T2).** Их ловят детектор людей с трекингом + состояние 4 объектов (стол, сейф, ноутбук, дверь) — правила поверх, без обучения сложной модели.
2. **T9/T8/T10 — про действия рук с деньгами**: нужны позы (руки) + детекция купюр/сумки + регион счётной машины. Самые трудные, их лучше подтверждать людьми.
3. Таймкод в разметке = момент начала нарушения (уход, вход, передача). Выдаём ту же секунду и кадр-доказательство из неё ±1 с.
4. Нормативные источники для каждого типа — `data/laws/rules_catalog.json` и таблица в `docs/LAWS.md` (пункты правил НБРК № 231, № 14 и Требований АРРФР № 53 с дословными цитатами).
