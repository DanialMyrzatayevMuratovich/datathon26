# Журнал экспериментов

Каждый `app.cli auto` дописывает сюда строку сам: время · кто · run_id · лучшая модель и CV · что ушло в сабмит · заметка. Под строкой — вывод одной строкой (✔/✖ гипотеза — почему). Ручной эксперимент (ноутбук, Colab) — строку целиком сами. Файл сливается git без конфликтов (`merge=union`), поэтому только дописываем, ничего не правим.
