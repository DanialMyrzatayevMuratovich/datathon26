## Только для Claude Code
В этом репо правила ниже перекрывают `~/.claude/CLAUDE.md`:
- Коммиты прямо в `main` — ок (24 часа, без PR).
- Push — только через `scripts/checkpoint.sh "…"`, отдельно не спрашивай. Голый `git push` не делай.
- Dev-сервер можно запускать самому: один, на фиксированном порту (py 8000 / web 3000), после проверки — погасить.
- Новые зависимости — только после ОК лида (он владелец lockfile).
- Новые файлы: код, тесты, `notebooks/`, `docs/*`, `pitch/*`, `scripts/*`. Прочее в корне — только по просьбе.
- Долгие команды (обучение, `app.cli auto` на полном наборе, `tune`) запускай в фоне (run_in_background) и продолжай работу; результат придёт сам. Перед запуском оцени время на выборке (`--sample 50000` или `--quick`).
- Скиллы проекта: `/kickoff` (разбор ТЗ, лид), `/autopilot` (автономный цикл экспериментов), `/insights` (бизнес-инсайты из данных), `/pitch` (презентация), `/colab` (вынести обучение в Colab), `/checkpoint`, `/critics`, `/ship`; `/grilling` — прожарка идеи или плана раундами вопросов с рекомендованными ответами. Для любого UI — `ui-craft` (облик + движение + тексты; ревью UI — таблицей Before | After | Why).
- Ночной режим без человека: `/loop /autopilot` — агент сам выбирает следующий эксперимент, запускает, пишет вывод в `docs/EXPERIMENTS.md` и пушит.
- Строка «⏱ …» в начале запроса — где мы в 24 часах, твоя роль и зона, что делает напарник: подгоняй объём работы под время и не выходи за зону. Под ней — «💬» новые сообщения команды: ответь или учти их в работе.
- Ждёшь ответа или результата от напарника — запусти `scripts/msg.sh wait` в фоне (run_in_background): когда придёт сообщение, ты проснёшься сам. Пока ждёшь — делай свою часть.
- Графики для питча — по скиллу `dataviz`, если он доступен; иначе matplotlib с подписанными осями и одним выводом в заголовке.
