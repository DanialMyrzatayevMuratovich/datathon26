# Checkpoint

1. Кто ты: `git config dt.role`. Пусто → спроси человека, `scripts/setup.sh <id>`.
2. `git status` и `git diff --stat`. В коммит должно попасть только твоё; чужое или случайное (большие файлы, данные, `.ipynb` с выводом на мегабайты) — спроси человека.
3. Обнови свой `docs/tasks/<id>.md`: сделанное — в «Готово» с R-ID и run_id, следующая задача — в «Сейчас».
4. Сформулируй одной строкой на английском, что сделано (≤80 символов, с R-ID), и запусти `scripts/checkpoint.sh "<строка>"`.
5. Скрипт остановился:
   - **секрет** → найди файл:строку из вывода, перенеси значение в `.env.local`, повтори. Сам секрет не печатай;
   - **сырые данные** (`data/raw/…`) → `git restore --staged <файл>`; данные организаторов в git не идут. Разрешили явно → `ALLOW_DATA=1`;
   - **чужая зона** → верни файл (`git restore --staged --worktree <файл>`) или договорись через человека и повтори с `ZONE_OK=1`;
   - **конфликт** → коммит остался локально, репо чистое. Файл своей зоны: `git pull --rebase`, поправь, `git add`, `git rebase --continue`, снова checkpoint. Чужой — не трогай, скажи человеку;
   - **push из песочницы Codex не проходит** → попроси человека одобрить запрос или выполнить команду в терминале.
6. Ответ — одна строка: время, id, хэш, статус тестов.
